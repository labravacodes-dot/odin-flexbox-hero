# Hero Analysis: Quirk

> *"If you want to become a hero, you have to look beyond what's right in front of you."* — Izuku Midoriya

## Overview
**Hero Analysis: Quirk** is a custom, fully responsive landing page built as a creative spin on the classic Flexbox landing page project from **The Odin Project**. 

The project is styled as a digital extension of Izuku Midoriya’s iconic tactical journals from *My Hero Academia* (specifically Analysis Notebook No. 13). It features detailed field observations, quirk mechanics, combat data, and frantic, high-speed muttering breakdowns focused on heroes like Katsuki Bakugo.

---

## The Inspiration: Why *Hero Analysis*?
When working through The Odin Project's default landing page layout, everything clicked the exact moment I saw the standard dark header block and that signature green tone. It immediately brought to mind Deku's classic hero suit and his exhaustive notebook entries. What started as a standard layout exercise instantly transformed into a creative vision: *The flexbox landing page had to be a hero analysis notebook.*

---

## Features
- **Custom Sans-Serif Typography:** Uses local **Roboto** font files (`Regular`, `Bold`, `Black`) mapped via `@font-face` declarations.
- **Thematic Navigation:** Custom-tailored header links including *Hero Trivia*, *Hero Analysis Strategies*, and *Training Notes*.
- **In-Character Copywriting:** Hero sections featuring authentic, hyper-focused "muttering" breakdowns capturing Deku's frantic analytical style.
- **Responsive CSS Grid & Flexbox:** Clean layout cards and structured containers adapting seamlessly across screen sizes.
